# 锅Bar · 开锅，碰杯

餐厅手机点单交互原型，支持手机与宽屏浏览。

## 体验内容

- 左侧两级折叠菜单：锅底、蔬菜、肉类、海鲜、精酿啤酒、葡萄酒、威士忌、干邑、鸡尾酒、套餐与限定。
- 锅底详情、辣度与份数选择、加购反馈。
- 购物车数量与金额联动，直接修改口味和份数。
- 跨分类搜索和浏览器本地已选菜单保存。
- 提交示例订单与演示完成反馈。

菜单、价格、桌号和图片均为展示内容；当前页面不产生真实订单或付款。

## 发布

静态入口为 `index.html`，图片随仓库保存于 `assets/`。GitHub Pages 使用 main 分支根目录发布。

## 本地预览

在仓库目录运行 `python3 -m http.server 8080`，浏览器访问 `http://localhost:8080`。

## 素材

Logo 来自项目提供的品牌源文件。红油锅与番茄锅图片为 AI 概念示意，其余品类摄影来源见 [ASSETS.md](ASSETS.md)。请替换成门店实际菜单与实拍素材后再用于真实营业。
